The mechanism: a script becomes a narrated, subtitled video through selectable local or remote providers. Preserve every generation setting and integration without a Python UI session.

FIRST VIEWPORT: a compact app bar, a stage rail (script, footage, sound, subtitles), a generous script editing surface, and a right-hand output monitor. The primary action stays beside a concise project summary. No promotional hero, stock illustration, sample results, or invented metrics.

Signature interaction: stage switching updates only the local editor while the output monitor and active generation remain present. Native video/audio players use authenticated same-origin files. Network polling exists only for active jobs and pauses when the document is hidden.

System: warm off-white canvas, white working surfaces, charcoal text, a restrained forest-green action accent. System UI typography and native controls are intentional for the low-resource local usage scene. Dark mode follows the same hierarchy. Rules organize work rather than enclosing every field in a card.

Responsive: rail becomes a compact wrapping stage bar; the output monitor moves below the editor. Controls remain keyboard-accessible, text labels stay visible, error messages identify recovery actions, and reduced motion is respected.

Honest risk: the number of integrations can overwhelm a new user. Show common settings first, retain advanced options in named expandable groups, and explain what is loaded or charged only when that action is requested.
