# MoneyMachine

MoneyMachine は、台本・映像・音声・字幕・音楽から短い動画を作成するスタジオです。

インストールと使用方法は [English](README-en.md) または [Português brasileiro](README.md) を参照してください。

LucasGazula が独立して管理しています。Harry の [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) を基に作成され、現在は独自に開発しています。元の Git 履歴と著作権表示は [MIT ライセンス](LICENSE) に従って保持されています。
